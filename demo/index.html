c2pa-verifier 0.5.0 · demo

Check the Content Credentials of an image

Pure PHP, running in your browser through WebAssembly: no server and no c2patool involved. Your file never leaves your device. The verdict uses the same terms as c2patool, the command-line tool from the Content Authenticity Initiative: Valid, Invalid or Trusted, with the C2PA status codes. It has been measured against it; where this verifier is stricter, the comparison says why.
